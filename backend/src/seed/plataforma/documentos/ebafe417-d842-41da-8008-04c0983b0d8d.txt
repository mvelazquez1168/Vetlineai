Clinical Report Specification — ECIS

Versión: 1.0
Código: ECIS-REP-001

1. Filosofía del Informe

Cinco objetivos: Documento Médico, Segunda Opinión, Documento Legal, Documento Científico (exponiendo la prueba de estimulación usada y su interpretación), Documento de Conocimiento.

2. Tipos de Reporte

CR-001 a CR-006 y CR-009, igual que en OCIS-REP-001/CCIS-REP-001. Se remueve CR-008.

3. Report Architecture

Portada → Executive Summary → Patient Information → Reason for Consultation → Clinical History → Timeline → Physical Examination → Laboratory Analysis → Endocrine Stimulation Testing → Diagnostic Confirmation Summary → Diagnostic Reasoning → Differential Diagnosis → Therapeutic Monitoring History → Clinical Evolution → Current Status → Prognosis → Recommendations → Firma y Certificación → References → Appendices

4. Secciones propias de ECIS

- **Endocrine Stimulation Testing** (sección propia): prueba(s) realizadas, resultados, valores de referencia, interpretación.
- **Diagnostic Confirmation Summary**: estado de confirmación (confirmado/presuntivo/descartado), criterios evaluados y pendientes.
- **Therapeutic Monitoring History**: clases farmacológicas activas, fase de titulación, resultados de retesteos sucesivos, ajustes realizados y su justificación.

5. Resto de secciones

Idénticas en estructura a OCIS-REP-001/CCIS-REP-001 (Firma y Certificación con las mismas reglas, Export Formats, Architecture Decisions con la misma remoción de "Versión de Derivación").

6. Clinical Quality Checklist — adaptación relevante

Confirmación diagnóstica: ¿se realizó la prueba de estimulación apropiada? ¿el diagnóstico se presenta como confirmado solo cuando la prueba lo respalda? Monitoreo: ¿el esquema activo tiene su próximo retesteo documentado?

Formato del Marcado en Secciones de Texto Libre

Las secciones de texto libre del informe (Historia Clínica, Razonamiento Diagnóstico, Evolución Clínica, contenido de apéndices, y cualquier otra sección sin una estructura de campos fija) se renderizan interpretando el marcado: negrita, cursiva, encabezados de nivel 2 (## Título), listas con viñeta y numeradas, y tablas en formato markdown.

Si el contenido de una de estas secciones se subdivide internamente, esa subdivisión deberá marcarse con un encabezado de nivel 2 (## Título) — nunca con negrita a modo de título.

La negrita (**texto**) queda reservada exclusivamente para destacar una palabra o frase dentro de un párrafo, nunca como sustituto de un encabezado.

Si el texto anuncia una cantidad de partes, elementos o pilares ("en base a X pilares..."), esa cantidad deberá coincidir exactamente con la cantidad que efectivamente se enumera a continuación. Ante la duda, no anunciar una cantidad específica.
