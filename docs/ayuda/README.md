# Manual de usuario — Vetline Clinic

Esto es el manual de Vetline Clinic y, a la vez, la fuente de la que el agente de ayuda responde
cuando alguien pregunta cómo se hace algo. Continúa el manual de usuario de Vetline Ai que ya
existe en `docs/Vetline_Ai_Manual_de_Usuario.docx`.

**Está escrito para alguien que sabe de veterinaria y no tiene por qué saber de administración, de
finanzas ni de facturación electrónica.** Si una página usa una palabra del mundo contable o
fiscal, esa palabra está en el [glosario](glosario.md).

## Cómo está organizado

Cada funcionalidad tiene su página, y cada página dice siempre lo mismo y en el mismo orden:

1. **Para qué sirve** — qué problema de la clínica resuelve.
2. **Cuándo se usa.**
3. **Quién puede usarla** — qué rol.
4. **Paso a paso**, con el camino de clics.
5. **Un ejemplo con números.**
6. **Qué pasa después** — qué se cobra, qué se descuenta del inventario, qué se avisa, qué ve el
   cliente.
7. **Preguntas frecuentes y errores comunes.**

## Lo que todavía no está en este manual

Las páginas se agregan con cada entrega. Hoy están las del **prompt 07c** (la atención), las del
**07d** (el dictado por voz), las del **anexo 07-03** (el paciente, el cliente y los duplicados),
las del **08b/09b** (presupuestos, cierre de caja, descuentos, facturas de proveedores y actividad
económica) las del **04** (personal y roles, horario y feriados, políticas) las del **10a** (cuentas por pagar, gastos, cobranza y cierre del
día) las del **11** (catálogos, turnos y comisiones, cumplimiento y auditoría) la del **16a** (la
ayuda que responde con estas mismas páginas) y las del **12** (los reportes y la trazabilidad de un
producto). Faltan las del resto de caja, inventario y agenda, que
se irán sumando.

**Desde el 16a, estas páginas no son solo un manual:** son la fuente con la que el sistema contesta
«¿cómo hago…?». Cada entrega que agregue o cambie una pantalla actualiza su página acá, y el
despliegue corre `npm run cargar-ayuda` para que el agente responda con lo último.

El manual consolidado en PDF y Word, con el logo de la clínica, se genera **al cierre de cada
bloque**, no en cada entrega.
